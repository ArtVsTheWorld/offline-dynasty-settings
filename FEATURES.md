# Ace’s Extra Settings 0.2.12

## Pick the rules for your Dynasty

Open **League Settings > Game Settings** in an offline Dynasty. Look just above Clock Management for six choices. A new league starts with the normal offensive clock, a 15-second defensive clock and all four playcall rules off. Start a fresh game to try your changes.

| Setting | Choices | What it changes |
| --- | --- | --- |
| Offensive Play Clock | On, Off At Playcall, Off, 60 Seconds | On uses the normal clock. Off At Playcall pauses it while you pick a play. Off turns off the offensive countdown and delay-of-game penalties. 60 Seconds gives the offense a longer count. |
| Defensive Play Clock | 3, 5, 15, 20, 30, 45 or 60 seconds, or Off | Sets how long the defense has to choose a play. |
| Offensive Playcall Cooldown | 0–10 plays | How many other plays the offense must run before it can repeat a call. |
| Defensive Playcall Cooldown | 0–10 plays | How many other calls the defense must make before repeating a call. |
| Offensive Playcall Limit | 0–20 uses | How many times the offense can call the same play in one game. |
| Defensive Playcall Limit | 0–20 uses | How many times the defense can call the same play in one game. |

Set any cooldown or limit to **0** to turn just that rule off. For example, give your offense a cooldown of **2** and a limit of **3**. You can call a screen, call two other plays, then call the screen again. After the third screen, you have used it up for that game.

## Switch teams during a game

In a supported offline Dynasty match, open **Pause > Options > Controller Select**. Move your controller to the other team and confirm. You take over at the next play-selection screen. The CPU runs the side you left.

This switch works with one controller and full-team control. Play Now, online games, practice, player lock and matches with multiple users are outside its scope. In Expanded Practice, the practice menu has its own **Flip Sides**.

## Keep your choices

Each Dynasty has its own settings. The mod reads the league's identity from the game. Renaming a save file does not make a new league. A saving helper can keep working if you close MMC while that game is still open. It leaves when the game session ends.

Copies of MMC on the same Windows account share the ExtraSettings data folder. Older settings stay available during an update. If the game or another mod changes a control this version needs, the affected feature can stay off. The report names the part that could not start or save.

This mod works on its own. See **ExtraSettings-Player-Guide.pdf** in the ZIP for pictures and help.
